Advertising purchases are limited to placement only

Advertising purchases here cover display placement only. They do not change feature access, subscription plans, message history, or any other monetization feature. Agents request:

  • Which Ad Type they want (Property Ads, Featured Properties, Agent Info Advertisement)
  • Which slot they prefer (out of 5 fixed slots per Ad Type)
  • Which period they are interested in (placeholder only)

2. Advertising Rules (Text Block)
  • Ads are not guaranteed permanent placement. They occupy a slot for a defined period only.
  • Each Ad Type has exactly 5 fixed slots. No overflow beyond these slots is shown here.
  • When a slot is Available, it may participate in fallback logic for that Ad Type.
  • Fallback display logic is applied when all slots for an Ad Type are empty or not Active:
    • Ad Type 1 – Paid Property Advertisement Slots: fallback shows newly listed for-sale properties limited to new construction and condominium developments uploaded within the past month.
    • Ad Type 2 – Featured Properties: fallback shows properties uploaded within the past month excluding new construction and condominium developments.
    • Ad Type 3 – Agent Info Advertisement: no property fallback; if no active ads, “Featured Agents” may show default non-promoted content (not detailed here).
Exact rotation, priority between multiple active ads, and detailed fallback sampling method are to be confirmed with client.
3. Governance Disclaimer
  • Admin does not modify ad content. Ad creative and copy are supplied by agents or another workflow.
  • Admin manages slot availability only: which slots are Active, Pending Approval, Available or Expired.
  • Admin views are focused on:
    • Slot status and limited attribution (e.g. which agent requested the slot, in high level).
    • Compliance with platform policies (not detailed here).
  • Any additional legal / compliance rules (e.g. jurisdiction, disclaimers, content restrictions) are to be confirmed with client and legal teams.
