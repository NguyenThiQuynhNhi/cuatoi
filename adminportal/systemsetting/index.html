Basic Settings

Configure system-wide defaults used across Client, Agent, and Admin portals. These values are referenced everywhere and should only be changed by Super Admin.

Global defaults System-wide
Default currency
Used for billing, financial reports, and default price display across portals.
Default language
Baseline language for Client, Agent, and Admin portals before any per-user preference.
Timezone
Reference timezone for system jobs, logs, and all timestamps.
Area unit
Default area unit for listings and search filters (Client and Agent portals).
Saved items limits Client portal
Max saved properties per user
Limits how many properties a single end user can keep in their Saved Properties list.
0 = no hard limit
Max saved searches per user
Limits how many search definitions a single end user can store (for alerts, quick access, etc.).
0 = no hard limit
Unsaved changes
Changes will update defaults across Client, Agent, and Admin portals.

Transaction Data Input Settings

Configure mandatory transaction-related rules when agents update or remove a listing. Removal reasons configured here appear as options for agents when they close or hide a listing.

Removal reasons configuration
Reason label (agent-facing) Additional requirement Status
Sold Price required; mark as public or private to Yuushi Active
Sold by others Optional note Active
Owner did not want to sell Reason text optional Active

Add or remove reasons here to control the options shown to agents when they close or hide a listing. These rules are referenced by Customer Portal (C46, C47) and Agent Portal (B30). Changes should be coordinated with those teams.

No coding required — this is pure configuration of labels and rules.
